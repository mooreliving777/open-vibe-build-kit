# Contributing to Open Vibe Build Kit

Thanks for helping other developers learn by building.

1. Read the [Code of Conduct](CODE_OF_CONDUCT.md) and open a focused issue before substantial new features.
2. Fork the repository and work on a small branch. Never include API keys, tokens, or real customer data.
3. Run `node --test` and `node bin/ovbk.mjs audit .` locally. Verify examples manually when they require installed dependencies.
4. Keep changes understandable: explain the problem, why you chose this solution, and how to test it.
5. Open a pull request for review. No automatic merge or production publishing is promised.

Bug fixes, clear documentation, translations, accessibility improvements, and example tests are particularly valuable. Contributions are MIT licensed when merged unless otherwise agreed in writing. Do not copy third-party tutorials, artwork, trademarks, or proprietary source code without compatible permission.

**Noncommercial project boundary:** This repository does not operate a paid service, solicit customers, provide paid support, or host client sites. Commercial requests should not be routed into this project.
