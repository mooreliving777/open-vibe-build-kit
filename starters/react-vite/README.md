# React/Vite starter

A teaching starter with React and Vite. Review the package versions before installation or production.

```bash
npm install
npm run dev
npm run build
```

The resulting `dist/` folder can be hosted on a static site service, including Netlify. The root `netlify.toml` in the full Open Vibe Build Kit archive is for the **documentation site**, not this sample; if deploying the starter separately, use build command `npm run build` and publish directory `dist`.

Nothing here connects to a real API or database and no secrets should be added to the browser bundle. The template has no customer signup or monetization.
