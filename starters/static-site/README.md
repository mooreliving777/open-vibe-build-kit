# Static website starter

A tiny, accessible website with **no dependencies**. Open `index.html` in your browser or run `python -m http.server 8080` in this folder. Edit the text and styles, then audit and test it before publishing. No analytics, account sign-in, or third-party requests are included.

For Netlify, use publish directory `.` when this starter is in its own repository, or point the site's base/publish settings to this directory. Do not select a paid plan automatically.
