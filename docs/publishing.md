# Publishing and Netlify Open Source application checklist

This project has a public GitHub repository at https://github.com/mooreliving777/open-vibe-build-kit. A deployed website or Open Source plan approval is **not** implied by the source repository.

## GitHub

- [x] Create the public repository `open-vibe-build-kit` under a personal GitHub account.
- [x] Add the license, Code of Conduct, contribution guidance, and initial community documentation.
- [x] Confirm all project files and tests are present after the latest commit.
- [x] Run GitHub Actions CI and verify tests pass.
- [ ] Confirm this is actually maintained for open collaboration, not as a lead-generation or paid-service channel.

## Netlify

- [ ] Start with the regular Free plan; no subscription upgrade or paid add-ons.
- [ ] Import this repository to Netlify and publish static documentation from `site`.
- [ ] Check the actual deployment for working navigation and the Code of Conduct.
- [ ] Verify visible **This site is powered by Netlify** attribution on the homepage.
- [ ] Collect the real deployed community website URL.
- [ ] Verify eligibility under the latest [Netlify Open Source policy](https://www.netlify.com/legal/open-source-policy/).
- [ ] Only then fill out the [official application form](https://opensource-form.netlify.com/).

## Application fields (fill from verified account information)

| Field | What to enter |
| --- | --- |
| Name | Actual maintainer name shown in Netlify account |
| Email associated with Netlify account | Actual signed-in Netlify email; never guess |
| License | `MIT` — from repository `LICENSE` |
| Code of Conduct link | https://github.com/mooreliving777/open-vibe-build-kit/blob/main/CODE_OF_CONDUCT.md |
| Project link | Public repository and actual deployed community website |
| Additional details | Accurate description of the toolkit's educational, noncommercial purpose and open collaboration; no sales or hosting services |

## Suggested additional-details text

> Open Vibe Build Kit is a freely available, MIT-licensed, noncommercial educational open-source toolkit. It provides community documentation, an offline starter CLI, sample static/React/Node projects, and security-focused learning examples. Participation is open through GitHub issues and pull requests. The requested site hosts documentation for this project only, with a public Code of Conduct and Netlify attribution. This project does not provide paid services, host client sites, sell subscriptions, or function as a customer acquisition funnel.

**Important:** Submit the text only if each statement remains true after launch. Netlify reviews eligibility. Applications are not automatically accepted.
